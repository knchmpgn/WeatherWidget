# WeatherWidget

A lightweight Windows taskbar weather widget built with .NET 8 that displays current weather information.

## Features

- Real-time weather display
- Modern .NET 8 application architecture
- FluentUI / WinUI design aesthetic
- Fully portable

## Project Structure

```text
WeatherWidget/
├── Models/         # Weather data models
├── Services/       # Weather API and data services
├── Views/          # Application UI and widget views
├── Properties/     # Application settings and metadata
├── Assets/         # Icons and image resources
├── App.xaml        # Application entry point
└── WeatherWidget.csproj
```

## Requirements

- Windows 10/11
- .NET 8 SDK or Runtime
